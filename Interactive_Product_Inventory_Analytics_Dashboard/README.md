# Interactive Product Inventory & Analytics Dashboard

A browser-based mini project based on the Capstone section in `JavaScript Assignments and Mini Project`.

## Run it
1. Extract the ZIP.
2. Open `index.html` in Chrome, Edge, or Firefox.
3. Click **Add product** to add a name and price.
4. Search/filter products, remove items, review the analytics and copy the report.

No Node.js, database, packages, or internet connection are required.

## Features
- Add products with input validation and duplicate-name checking
- Dynamic Budget / Standard / Premium category badges
- Inventory table with search, category filter, and remove action
- Total inventory value, affordable item count, and premium count
- Affordable products list and formatted analytics report
- Reset sample data

## JavaScript concepts demonstrated
Variables/constants, objects and arrays, explicit `Number()` conversion, functions and arrow functions, default parameters, if/else, switch, for/forEach, filter, map, local scope, DOM events, and validation.

## Project files
- `index.html` — page structure
- `style.css` — responsive styling
- `script.js` — app logic and analytics

## Notes
This is a front-end mini project. Product changes live in the current browser tab and reset when the page is refreshed. A database/persistent storage layer is not included.
